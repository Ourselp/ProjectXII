# projectZero

Astrub (Dofus 3 assets) with a walking Iop: click a cell to move, walk off an edge to change map.

```bash
npx http-server public -p 8123   # then open http://127.0.0.1:8123
```

`public/chartest.html` shows the character animations alone. How the assets are extracted: [docs/extraction.md](docs/extraction.md).
