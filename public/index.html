Aide

Clic sur une case : se déplacer (course au-delà de 3 cases).
Clic au-delà d'un bord : changer de carte (flèche verte = sortie possible).
Raccourcis : C caractéristiques, S sorts, I inventaire, Q quêtes, U succès, J métiers, B encyclopédie, F amis, G guilde, D montures, A apparence, M carte, O options, H aide, 1–0 sorts, Entrée chat, Échap fermer.
Commandes : /tp 5,-18 ou /tp <id de carte>, /stats (nouvelles caractéristiques), /hud (replacer l'interface).
Interface : survoler un module fait apparaître son bandeau, qui sert à le déplacer.
